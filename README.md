# Praktikum Font Recognition CNN

Praktikum Deep Learning menggunakan metode Convolutional Neural Network (CNN) untuk klasifikasi jenis font.

## Dataset
https://www.kaggle.com/datasets/dhruvmak/font-recognition-data

## Tools
- Google Colab
- Python
- TensorFlow
- Keras

## Metode
Convolutional Neural Network (CNN)

## Hasil
Model berhasil melakukan klasifikasi jenis font menggunakan dataset gambar font.
